# Desafio Recriando a Página do Discord

Desafio do curso da DIO, no qual eu reproduzi a página da incrível plataforma do **Discord**. O foco principal foi colocar em prática tudo que aprendi até agora, principalmente sobre **responsividade no CSS**.

## Tecnologias usadas

- HTML
- CSS (Flexbox, Grid e Media Queries)
- Responsividade para mobile, tablet e desktop

## Estrutura do projeto

/assets
/css
style.css
/images
logo.png
index.html

## Como abrir o projeto

Basta abrir o arquivo `index.html` no navegador que ele funciona normalmente.

## Sobre o projeto

O desafio foi ótimo para reforçar conceitos de **layout e responsividade**.  
Procurei manter a aparência o mais próxima possível da página original do Discord, praticando posicionamento, cores, fontes e ajustes para diferentes telas.  

Feito com dedicação e foco em aprendizado! 💜
